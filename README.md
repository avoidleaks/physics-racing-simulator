# 🏎️ Physics Racing Simulator / ფიზიკის სარბოლო სიმულატორი

An interactive browser-based physics simulation game built with HTML5 Canvas and JavaScript. Control acceleration and friction parameters to stop the car precisely on the target line!

ინტერაქტიული ბრაუზერული ფიზიკის სიმულატორი, შექმნილი HTML5 Canvas-ისა და JavaScript-ის გამოყენებით. მართეთ აჩქარებისა და ხახუნის პარამეტრები, რათა მანქანა ზუსტად სამიზნე ხაზზე გააჩეროთ!

---

## 🇬🇧 English

### 🎮 How to Play
Adjust your car's acceleration and track friction to reach the destination. Your primary objective is to bring the vehicle to a complete stop exactly on the **red stop line**. 

* **Perfect Stop**: Stop within 1.0 meter of the target line.
* **Avoid Overshooting**: Braking too late will cause you to pass the line!

### ⌨️ Controls
* `W` / `Up Arrow` : Increase Acceleration (+0.4)
* `S` / `Down Arrow` : Decrease Acceleration / Brake (-0.4)
* `A` / `Left Arrow` : Decrease Friction (-0.05)
* `D` / `Right Arrow` : Increase Friction (+0.05)
* `Spacebar` : Handbrake (Set acceleration to 0)
* `R` : Reset Simulation

### 🌐 Multilingual Support
This game natively supports multiple languages, including English, Georgian, Spanish, French, German, and Russian.

## 🇬🇪 ქართული

### 🎮 როგორ ვითამაშოთ
დაარეგულირეთ მანქანის აჩქარება და გზის ხახუნის კოეფიციენტი. თქვენი მთავარი მიზანია სატრანსპორტო საშუალება გააჩეროთ ზუსტად **წითელ გაჩერების ხაზზე**.

* **ზუსტი გაჩერება**: გაჩერდით სამიზნე ხაზიდან 1.0 მეტრის რადიუსში.
* **მოერიდეთ გადაცილებას**: გვიან დამუხრუჭებისას გასცდებით ხაზს!

### ⌨️ მართვის ღილაკები
* `W` / `ზედა ისარი` : აჩქარების მომატება (+0.4)
* `S` / `ქვედა ისარი` : აჩქარების შემცირება / მუხრუჭი (-0.4)
* `A` / `მარცხენა ისარი` : ხახუნის შემცირება (-0.05)
* `D` / `მარჯვენა ისარი` : ხახუნის მომატება (+0.05)
* `Space` : ხელის მუხრუჭი (აჩქარების 0-ზე დაყენება)
* `R` : სიმულაციის გადატვირთვა

### 🌐 მრავალენოვანი მხარდაჭერა
თამაშს აქვს რამდენიმე ენის მხარდაჭერა: ინგლისური, ქართული, ესპანური, ფრანგული, გერმანული და რუსული.
